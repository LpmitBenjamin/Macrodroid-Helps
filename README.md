# MacroDroid Helps

A collection of useful MacroDroid macros, Java code snippets, and shell scripts for Android automation.

Created and tested on Android 15 and with Macrodroid Pro.

---

## Features

- No root required
- No ADB required
- No Shizuku required
- Beginner and advanced examples

---

## Repository Structure

### 📁 Macros
Ready-to-use MacroDroid macros.

### 📁 Java Code
Useful Java snippets for MacroDroid and Android development.

### 📁 Shell Script (Toybox)
Shell scripts designed for Android Toybox environments.

---

## Notes

Some examples may require specific Android permissions depending on the functionality used.

All macros are available in the MacroDroid templates under the same names.
