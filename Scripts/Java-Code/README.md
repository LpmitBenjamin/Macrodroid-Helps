# Java Code

## 🔴 [Reading calendar data](https://github.com/LpmitBenjamin/Macrodroid-Helps/blob/main/Scripts/Java-Code/Reading%20calendar%20data.js)
Reads all available calendars from the Android database and outputs their ID, name, and account information.

## 🔴 [Read out WLAN frequency](https://github.com/LpmitBenjamin/Macrodroid-Helps/blob/main/Scripts/Java-Code/Reading%20the%20WLAN%20frequency.js)
It reads the current Wi-Fi frequency and detects whether the device is connected to the 2.4 GHz or 5 GHz network.

## 🔴 [Detect active network type](https://github.com/LpmitBenjamin/Macrodroid-Helps/blob/main/Scripts/Java-Code/Detect%20active%20network%20type.js)
It checks the current internet connection and indicates whether the device is connected via Wi-Fi, mobile data, or no network at all.

## 🔴 [Select images from gallery](https://github.com/LpmitBenjamin/Macrodroid-Helps/blob/main/Scripts/Java-Code/Select%20images%20from%20gallery.js)
Reads all images from the Android gallery and outputs filenames and storage paths sorted by the latest date.

## 🔴 [Read music files](https://github.com/LpmitBenjamin/Macrodroid-Helps/blob/main/Scripts/Java-Code/Read%20music%20files.js)
Reads all saved audio files and outputs the title and artist from the Android media library.
