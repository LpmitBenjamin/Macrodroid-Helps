# Macrodroid-Macros
All macros are available in the MacroDroid templates under the same names.  
If you like the macros, I would appreciate a star rating.

## 🔴 [Speed_indicator.macro](https://www.macrodroidlink.com/macrostore?id=16549)
This MacroDroid macro lets you monitor your driving speed using GPS data. 

## 🔴 [Screen_Reader.macro](https://www.macrodroidlink.com/macrostore?id=19184)
This MacroDroid macro reads the current screen content and displays it in an easy-to-read dialog. 

## 🔴 [Time_calculator.macro](https://www.macrodroidlink.com/macrostore?id=26187)
This MacroDroid macro calculates the time difference between a start and end time. 

## 🔴 [Action_test_button.macro](https://www.macrodroidlink.com/macrostore?id=15989)
This MacroDroid macro executes the currently opened macro with just one click, making testing faster and more convenient.
