## Description

This MacroDroid macro lets you monitor your driving speed using GPS data.

### Features
- Shows your current speed (last GPS speed)
- Tracks your highest speed since the last restart
- Simple and lightweight setup

### Important
If the macro is not working, your device is most likely not receiving GPS speed data.

In most cases, you can fix this by:
1. Opening Google Maps
2. Starting a route/navigation
3. Leaving it running in the background

This usually enables continuous GPS updates and allows the macro to work properly.
